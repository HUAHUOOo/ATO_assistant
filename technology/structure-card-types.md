# 结构科技细分

结构科技通过 `type.structure_card_types` 保存可多选标签。初始分类按本地卡面逐张核对，覆盖字典中全部 148 张结构科技卡，包括全部 30 张结构科技大卡；后续可以在科技页“已解锁科技 → 编辑科技卡分类”中调整。

大卡沿用科技页的尺寸判定：卡面裁剪宽度至少 1000 像素或高度至少 1300 像素。属性编辑器的“结构科技大卡”筛选可以集中查看这些卡牌。战斗科技（包括战斗科技大卡）不使用这些细分标签。

| 标签 | 字段值 | 分类依据 |
| --- | --- | --- |
| 一次性效果 | `one_time` | 卡面有“立即／Immediate”效果，获得科技时结算。 |
| 豁免 | `save` | 卡面有“豁免／Save”能力。 |
| 谈判 | `negotiation` | 谈判能力，以及字典已有的谈判标记。 |
| 主动 | `active` | 玩家选择使用、支付代价或发起的可重复能力；单独的谈判或豁免能力使用其对应标签。 |
| 参考 | `reference` | 卡面标为“参考／Reference”的规则说明。 |
| 永久 | `permanent` | 卡面标为“永久／Permanent”的效果；可以同时具有主动能力。 |
| 被动 | `passive` | 没有上述印刷关键字的自动触发效果或持续规则。 |
| 其他 | `other` | 后续需要记录、暂不属于上述类别的效果。 |

“永久”是卡面效果类型。跨循环是否仍可用继续由原有的 `loop_limited` 和循环范围决定。

`type.negotiation` 与细分中的 `negotiation` 同步，主控台谈判提醒和旧谈判编辑器可以继续读取。旧谈判编辑器只增减谈判标签，保留其余细分。
