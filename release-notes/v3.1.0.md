## 更新

3.1.0 正式版重绘了循环 I–V 的科技树：科技由可操作的节点与连接箭头组成，随着解锁逐步发现后续科技。保留原图的主要布局，并整理节点位置与连线路径，让科技关系更容易阅读。

**交互科技树**

- 点击节点查看介绍，双击节点或点击 ＋ 解锁；详情中新增“能解锁的科技”，便于查看后续发展方向。
- 支持逐步发现科技。没有满足下方条件的孤立科技显示为“未发现科技”，满足条件后才显示名称。
- 保留科技前置关系、条件检查与进度保存；发现新科技时，已有节点位置保持稳定。
- 使用紧凑的节点模块，重新调整节点高度、箭头间距与入口方向，尽量让同一条发展路线水平对齐。

**布局与连线优化**

- 整理五个循环的科技位置，减少无意义的折线；调整循环 II 的阿尔戈号安保、战争募员与创伤复原之间的连线。
- 重新梳理循环 IV 战斗科技的分支与连线通道，拉开相邻长线的距离；调整循环 V 等节点的高度，使相连科技尽量直线连接。
- 重叠线段统一绘制，避免叠加后变粗；箭头独立显示，减少交叉线遮挡，并尽量区分节点的进线与出线位置。
- 科技树恢复带边框的视图区，进入页面时自动居中并适配显示大小，减少左右空白。支持缩放、拖动、总览与定位可解锁科技。
- 删除重复的循环科技树标题及说明栏，保留进度统计与必要的视图操作。
- 移除资源清单中的五张科技树底图及 `technology/images/tech_tree_pages/` 目录；Android 不再要求导入这些底图，新资源包也不再包含它们。科技卡、装备卡与泰坦职业配图继续保留。

**界面细节**

- 当前循环标签可打开循环选择菜单，便于在循环 I–V 之间切换；标签高度与工具栏控件保持一致。
- 装备制造卡片减少外层边框，科技分组标题与装备卡片采用不同样式，层级更清楚。
- 略微加深 AIBP 与故事书侧栏底色，改善侧栏与主内容的区分。

## 下载与升级

本版本为正式版，提供 Android APK、Windows x64、macOS Apple Silicon / Intel 便携版，以及 Docker 镜像 `3.1.0`；正式发布同时更新 Docker 的 `latest` 标签。

- Android：下载 `ATO-Assistant-3.1.0.apk`，覆盖安装。
- Windows：下载 `ATO-Assistant-Portable-3.1.0-windows-x64.zip`，或使用便携版内置更新。
- macOS：根据芯片下载 `ATO-Assistant-Portable-3.1.0-macos-arm64.zip` 或 `ATO-Assistant-Portable-3.1.0-macos-x64.zip`。
- Docker：使用原部署配置拉取与重建；固定版本用户将 `ATO_VERSION` 改为 `3.1.0`。

从 3.0.0 升级无需因本次科技树更新重新导入资源包。手动替换程序时保留原来的 `data/` 与本地素材目录。公开程序包继续不包含游戏图片、完整故事、音乐、资源包或用户存档。
