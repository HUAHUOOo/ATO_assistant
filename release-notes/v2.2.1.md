## 更新

本版为 2.2.1 正式版，汇总 rc.1 至 rc.4 的战斗界面、卡图与资源清单更新，并修复独立素材库工具（Asset Studio）的上传资源限制。

**AIBP 自定义特性与 Token**

- Trait 界面支持创建、预览、编辑自定义特性，填写名称和规则内容；按使徒分别保存，支持同名条目，清空展示后仍可再次选用。
- 自定义特性卡面保留面具、骷髅插画与 X 角标；标题优先使用隶书，正文优先使用黑体，自动换行和调整字号，超出卡面时提示缩短。
- Token 界面支持自定义文字标记，使用圆形卡底，支持换行、数量调整、拖动定位和放大查看；文字、数量与位置随战役保存。
- 自定义特性与标记在主界面、放大查看及第二屏同步显示；同名标记仍可独立操作。

**战斗面板、地形与资源清单**

- 补全 Boss 地图地形。
- 超时光先知的全幅特性卡按 V 级登记，等级 5 起显示；旧存档中 O/1、IV/1 的选择自动迁移到 V/1，界面、清单与资源目标路径统一。
- 乌尔-弗里斯新增第二张完整面板，主界面与第二屏默认显示；可在面板和放大图中切回原面板，选择随存档保存并同步。
- 哈尔皮“急速适应 / 极速适应”采用竖版特性卡尺寸，民间版与官方版资源包使用对应卡面；退掉尼采超人清单中的重复笔误条目。
- 自定义特性卡底、自定义 Token 底图与新增面板纳入固定清单及 Android 导入名单。旧素材库升级清单时保留已导入图片。

**素材库上传保护**

- 上传请求在接收文件、解析表单和写入临时磁盘之前，先检查认证与并发限制。未经授权或名额已满的请求会直接被拒绝。
- 保护覆盖逐张拍摄、分块传输、完成处理、批量导入、故事文件、资料包上传及资料包导入。后台解析结束前仍占用处理名额。
- 同一客户端 IP 最多同时执行 2 个上传请求，全服务最多同时执行 8 个。同一 IP 每分钟最多发起 30 次上传或资料包导入，全服务每分钟最多 120 次；分块传输和完成处理不逐块消耗发起次数。
- 限制按客户端 IP 计数，避免更换会话 Cookie 绕过。超限返回 429，并提供重试等待时间；共享同一 IP 的设备也共享该额度。
- 按实际接收字节数检查请求体大小，未提供或错误声明 Content-Length 的请求也受到限制。
- 异常、取消或正常处理结束后释放并发名额，清理过期计数，避免上传额度被永久占用。

**上传失败后可以重试**

- 修复拍摄页面上传失败后按钮一直不可用的问题。开始上传、传输分块或完成处理失败时，进度提示与按钮状态会恢复，用户可稍后再次点击上传，并沿用已有的断点续传。

## 下载与升级

本版本为正式版，提供 Android APK、Windows x64、macOS Apple Silicon / Intel 便携版，以及对应版本的 Docker 镜像。

**素材库用户请更新源码工具。** Asset Studio 是独立的 Python 工具，现有 APK、便携版及 Docker 镜像不包含它。仅升级这些安装包，无法更新素材库上传接口。

1. 下载本页的 **Source code (zip)**，或将 Git 源码更新到 `v2.2.1`。
2. 使用新版源码中的 `asset-studio/`。若覆盖旧工具目录，请保留原来的 `asset-studio/.local/` 配置和用户自行建立的资料库目录。
3. Windows 运行 `asset-studio/start-windows.bat`；macOS 运行 `asset-studio/start-macos.command`。更新后重新启动素材库服务。

已有 ATO Assistant 用户可按原方式升级程序：便携版使用内置更新或替换程序目录，Android 覆盖安装 APK。Docker 使用版本标签 `2.2.1`，本次正式发布同时更新 `latest`。

从 2.2.0 或更早版本升级时，请同时更新与本版清单对应的 `.atopack` 资源包，以获得新增卡底、面板及修订卡面；Android 请先安装本版 APK，再导入新版资源包。已使用 rc.4 程序和对应资源包的用户可继续沿用资源包，无需因本次上传保护修复重新导入。

自定义特性的名称、规则内容及自定义 Token 文字保存为战役数据；资源包提供卡底与卡图。设备缺少隶书或黑体时会使用替代字体。公开程序包继续不包含游戏素材、完整故事、音乐、资源包或用户存档。
