## 更新

3.2.0 正式版新增科技页面军械库，集中管理装备库存与累计制造数量；同时修复主控制台、阿尔戈号记录表、英雄、地图和科技页面之间的存档同步问题，并改善日期轨道与流程提醒。本次统一发布当前工作区内各项已完成改动。

## 科技页面：新增军械库

- 科技页面新增「军械库」标签页，与「装备制造」入口并列。
- 在装备制造界面成功制造后，装备自动进入军械库：现有库存增加 1 件，累计制造数量同步增加 1 件；制造界面也显示该装备的当前库存。
- 制造扣料与装备入库在同一次记录表保存中完成。保存失败时不显示制造成功；遇到并发更新时重新读取最新记录、检查材料并重试，减少重复扣料或漏记装备的问题。
- 军械库分别显示「现有数量」和「累计制造」。手动补录、增加或减少数量只调整现有库存，不会改写累计制造数量；库存减到 0 后仍保留条目和制造历史，可用「只显示有库存」筛选隐藏零库存装备。
- 支持按装备分类、所属循环筛选，并按装备名称或编号搜索；显示已记录装备种类、库存总数和当前筛选结果的数量。
- 手动补录使用完整装备目录，包含不能制造的装备，不再仅限于生产配方中的装备。可以一次输入多件，也可以在装备条目中逐件增减。
- 库存跟随当前档案保存；操作期间切换档案会阻止继续向错误档案写入。制造、补录和资源调整增加了操作锁，避免保存期间重复点击。
- 「加入军械库」和「刷新」按钮文字改为水平、垂直居中，并与旁边的输入框对齐。

**已有装备如何处理**

升级前已经制造或获得、但未记录在军械库中的装备，可以从补录列表添加。本版本不会根据旧日志自动推算历史库存或累计制造数量。涉及装备材料、泰坦等需要人工处理的消耗，仍按界面提示手动处理；装备库存可在军械库扣除。

## 存档同步与冲突修复

- 修复旧存档中空对象、空数组、缺失字段和默认值补齐等格式差异导致的误报冲突，包括阿尔戈号记录表中的 `strangers` 及相关字段。
- 主控制台区分服务器原始存档与页面初始化后的保存基线，避免页面补齐默认值、初始化牌库等操作被误认为另一端修改了存档。
- 修复后台轮询与保存同时进行时的竞态，防止旧响应覆盖较新的保存基线或污染已经切换的会话。
- 英雄页面收到其他页面的更新通知后，读取服务器数据并合并尚未保存的本地修改，减少跨页面同步时覆盖编辑内容的情况。
- 地图页面统一当前板块、指示物等字段的默认结构；科技页面统一旧存档自动解锁与默认状态，减少初始化引起的假冲突。
- 科技同步快照不再额外触发保存；实际内容没有变化时，不再仅因更新时间不同重复写入主控制台。
- 不同字段的并行修改继续合并；同一个字段被两端实际修改时，仍保留冲突处理，不直接覆盖服务器内容。

## 主控制台：定数框与日期轨道

- 修复没有英雄时，在主控制台点击定数框后，阿尔戈号记录表出现日志却没有对应标记的问题。空存档中的冒险记录现在使用正确的对象结构保存，避免标记在 JSON 序列化时丢失。
- 主控制台定数框同步到当前循环、当前日期的记录，相关日志也写入对应位置，减少旧版顶层记录与分循环记录不一致的情况。
- 每次主控制台刷新、重新载入并渲染存档时，日期轨道自动定位到当前战役当天，方便继续处理当天流程。

## 主控制台：流程提醒配色

- 「下次战斗特殊板块」提醒增加浅底色，并继续显示板块名称、所属中枢与来源。
- 灾祸提醒使用浅红底色、深红左边框和红色标签。
- 进展提醒使用浅绿底色、深绿左边框和绿色标签。
- 将提醒规则放到实际生效的主控制台样式中，修复透明背景规则覆盖提醒底色的问题；更新样式版本，避免刷新后继续加载旧缓存。

## 科技树与 Docker 部署

- 科技树白色纸面只覆盖科技内容区域，随画布居中与缩放，不再强制铺满页面左右两端。
- 仓库根目录的 Apache / NAS Docker 配置补齐 `dashboard.css` 与 `cycle-theme.css` 挂载，避免该部署方式下主控制台样式与共享循环配色出现 404。使用此配置的用户需更新 compose 文件并重建容器。

## 下载与升级

本版本提供 Android APK、Windows x64、macOS Apple Silicon / Intel 便携版，以及 Docker 镜像 `3.2.0`；Docker 的 `latest` 标签同步更新。

- Android：下载 `ATO-Assistant-3.2.0.apk`，覆盖安装。
- Windows：下载 `ATO-Assistant-Portable-3.2.0-windows-x64.zip`，或使用便携版内置更新。
- macOS：按芯片选择 `ATO-Assistant-Portable-3.2.0-macos-arm64.zip` 或 `ATO-Assistant-Portable-3.2.0-macos-x64.zip`。
- Docker：拉取镜像并重建服务；固定版本用户将 `ATO_VERSION` 改为 `3.2.0`。仓库根目录的 Apache / NAS 部署请同时更新 compose 配置。

手动替换程序时保留原来的 `data/` 与本地素材目录。现有资源包可以继续使用，无需因本次升级重新下载或导入。公开程序包不包含游戏图片、完整故事、音乐、资源包或用户存档。
