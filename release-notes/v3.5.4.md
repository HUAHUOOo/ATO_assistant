## 更新

3.5.4 是一版内容与体验都较大的更新，汇总五组改动：

- **故事书行内图标全面换源**：99 个行内图标里的 95 个换成从官方 APK 提取的 44 个矢量母版，任何字号下都清晰；混排渲染器加固（不再破图、不再跳版）；C5 战斗标题按审计区间加粗。
- **朗读新增豆包语音合成（火山引擎）**：云端 API 与 MIMO、讯飞三选一。
- **修复一个发布级问题**：故事书渲染代码（`renderer.js`、`styles.css`、`story-tables.js`）此前从未进入版本库，导致从干净检出构建的 APK、Docker 镜像、便携包都缺这些文件——行内图文混排与正文表格会整体退化成纯文本，在线更新也送不到。现已入库并加上守卫测试。
- **Docker 与资料包侧**：修复无预构建镜像时的本地构建、Compose 挂载与密语字形导出/导入。
- **⚠️ 本版必须重新导入资源包**：新图标在资源包里，只更新程序看不到新图标。见「资源包」一节。

## 图标与渲染器

- 行内图标换成 **44 个从官方 APK 提取的矢量母版**（同一语义跨册共用一张），覆盖 99 个行内图标中的 95 个；C1 分神标记、C5 阿尔戈英雄火焰信封标识、C5 蓝色出口箭头、C5 秘密泰坦盒标识这 4 个含义在 APK 里找不到对应图案，保留原图，不拿别的图标冒充。
- 母版由用户提供的 APK 经 Unity 资源静态导出、alpha 等值线描摹为纯路径 SVG；包内附 44 张导出像素快照与逐条审计记录，可用随包脚本逐字节重建。
- 混排渲染器加固：图片解码成功后才显示；失败或超时（2 秒）自动回退原图、再回退原文；不再出现破图、不再占位跳版；点开放大的弹窗关闭与重挂时正确清理。
- C5 战斗标题按审计过的区间加粗（6 个条目 / 147 处），只改显示，正文文本、锚点与存档字节不变。
- 战斗版图维持书内裁图的既有口径（原 App 原生版图复用未启用）。
- **修复**：`story/assets/mixed-media/renderer.js`、`story/assets/mixed-media/styles.css`、`story/assets/story-tables.js` 此前只存在于开发机、没有提交到仓库（也没有被忽略规则拦住）。后果是从干净检出构建的 APK、Docker 镜像、便携包都不含它们：故事页 404，行内图文混排、C5 标题高亮与 C2 战斗表格整体退化成纯文本，在线更新也永远送不到。现已入库，并新增 `tools/test_story_code_in_git.py` 接进 CI——页面引用的代码若未提交会直接让检查失败，私有素材仍不会进仓库。

## 豆包语音合成（火山引擎）

- 朗读引擎配置的「云端 API → 服务商」新增第三项 **豆包语音合成（火山引擎）**，与 MIMO、讯飞三选一，配置区互斥显示。
- 字段：App ID / Access Token（鉴权头 `Authorization: Bearer;<token>`）、Cluster（默认 `volcano_tts`）、音色 `voice_type`（默认 `zh_female_wanqudashu_moon_bigtts`，输入框带 14 个常用大模型音色，可自行改写）、音频格式（mp3 / wav / ogg_opus）、采样率、语速倍率、音量倍率、接口地址（默认 `https://openspeech.bytedance.com/api/v1/tts`，可改成自建反代）、超时。
- 与既有引擎一样走浏览器直连，不新增服务端代理；同样支持分句朗读、预取、跳转预热与音频缓存（缓存键含接口地址、App ID、Cluster、音色、格式、采样率、语速、音量与文本，**不含 Access Token**）。支持逐音色试听。
- 常见错误码（3001 请求无效、3003 并发超限、3005 服务内部错误、3010 文本超长、4003 音色未授权、4001/401 鉴权失败）会带出原始 code 与提示；被跨域拦下时单独提示，此时把接口地址改成自建反代即可。
- 未配置 App ID / Access Token 时不会发请求。

## 资源包（本版必须更新）

| 资源包 | 大小 | 成员 |
| --- | --- | --- |
| `ATOassets-民间版-3.5.4-q85-2026-10-05.atopack` | 1.50 GiB | 4,862 |
| `ATOassets-官方版-3.5.4-q85-2026-10-05.atopack` | 2.64 GiB | 7,057 |

- **为什么必须更新**：图标素材（`mapping.js` 与 434 张裁图）随资源包分发，不随程序。旧资源包里的 95 个图标仍是旧图，只覆盖安装新版程序不会看到新图标。
- 导入方式：桌面用素材库「分享与安装」选择该 `.atopack`；Android 用 APK 里的资源包导入；Docker 把包内素材拷进 `app/`（见 `README-DOCKER.txt`）。
- Android 导入需要约 2× 包大小的可用空间（民间版约 3 GB，官方版约 5.3 GB）；空间紧可用 `--compress deflate` 重新打包。
- 资源包体积较大，不随本 Release 上传，请按原有渠道取用。
- 两个包都已用 `check_pack.py --crc --hash` 逐个成员复核：4,288 张图 + 84 张密语字形 + 435 个混合媒体成员的 SHA-256 与全部 CRC 一致。

## Docker

- 无预构建镜像时，安装脚本先生成与发布一致的程序包再本机构建，启动配置使用刚构建的镜像标签；重跑脚本可以更新本地镜像。
- Compose 支持 `ATO_IMAGE`。使用本地镜像时按安装说明设置镜像名称与拉取策略。
- 安装说明区分 Android 的界面导入和 Docker 的宿主机文件导入，补充密语字形目录 `app/story/assets/cryptic/glyphs/`。
- 解压到 `app/assets/bgm/` 的平铺音频可直接播放；已有 `audio/` 布局继续支持，播放器程序仍由镜像更新。
- 固定版本时用对应标签的 Compose 配置，避免新挂载配置遮住老镜像中的 AIBP 程序数据。
- Release 分发增加 Docker ZIP，其中包含 `README-DOCKER.txt`。
- 混合媒体素材（`story/assets/mixed-media/images/`、`mapping.js`）只挂素材那一层，程序代码（`renderer.js`、`styles.css`）由镜像提供——整目录挂载会让宿主目录遮住镜像里的新版本。

## 资料包与 Android

- 关闭「包含密语字形」或使用 `--no-cryptic` 后，字形不再混入普通图片资源，也不再要求工程目录有字形 PNG。
- 字形仅通过 `crypticFiles` 分发，保留原字节；图片压缩不再造成重复 ZIP 成员或安装目标冲突。桌面安装兼容旧包中的重复登记，以专用字形段为准。
- 桌面端可跳过单个校验失败的字形并导入其余资源，显示跳过数量、文件路径与原因。
- 素材库路径校验在 Linux、Windows 和 macOS 上一致拒绝盘符路径与冲突的大小写别名，避免跨平台搬运时出现安装冲突。
- Android 为 ZIP 成员、解压总量和实际读取字节设置上限，并核对清单声明的文件大小。资源与故事先暂存，再通过单个索引统一提交，失败保留原有安装结果。
- Android 导入完成提示会说明跳过的密语字形及原因。
- 探索卡映射检查扩展到五个循环全部 223 张普通与隐藏探索卡，另加入多循环、多隐藏卡的回归场景。资源包与导入回归检查在 PR 中运行。
- 混合媒体素材新增独立分发段 `mixedMediaFiles`（1 份映射表 + 434 张裁图），Android 导入时逐成员校验 SHA-256 与字节数，不符即跳过并计入 `mixed_media_skipped`。

## 升级

- **资源包**：重新导入上面那两个包之一；不导入可以正常游玩，只是新图标不会出现。
- Docker：重跑安装脚本以同步 Compose。手工部署请同步新版配置后重建容器，保留 `data/` 与 `app/` 中的素材。
- Android：覆盖安装新版 APK。已经安装的资源继续保留；需要新图标时重新导入资源包。
- 源码部署：拉取新代码后刷新页面即可（故事页脚本查询参数已更新，浏览器会重新拉取）。
- 第三方字形、图片、音频与私有故事数据仍需自行准备，不随程序或源码发布。
