## 更新

3.1.1 正式版统一第二屏幕的界面风格，故事书投屏新增双栏阅读，并调整 AIBP 的默认显示设置。

**第二屏幕与故事书**

- 第二屏幕改用与主站一致的浅色纸面和循环配色，支持同步全局主题；配对提示、战斗侧栏与卡牌区域同步调整底色和分隔线。
- 故事书投屏采用双栏正文，按左栏、右栏顺序阅读，栏间留出间距并以细线分隔；自动调整字号以适配可用空间。
- 标题改为与故事书主页面一致的宋体风格，段落编号去掉圆角底框，移除旧的深色背景、渐变与阴影。
- 官方故事书扫描图仍以整页图片显示；缺少扫描图或加载失败时，继续回退到正文。

**AIBP**

- 每次打开 AIBP 时，“查看牌背顺序”默认不勾选，避免之前保存的开启状态自动恢复；需要时仍可手动开启，并同步到第二屏幕。

**资源包**

- 资源内容与 3.1.0 相同，继续使用原有民间版与官方版资源包，无需重新下载或导入。Android 导入名单继续排除五张旧科技树底图及 `technology/images/tech_tree_pages/` 目录。
- 科技卡、装备卡、泰坦职业配图及其他素材继续保留。从 3.1.0 升级无需因本次界面调整重新导入资源。

## 下载与升级

本版本提供 Android APK、Windows x64、macOS Apple Silicon / Intel 便携版，以及 Docker 镜像 `3.1.1`；同时更新 Docker 的 `latest` 标签。

- Android：下载 `ATO-Assistant-3.1.1.apk`，覆盖安装。
- Windows：下载 `ATO-Assistant-Portable-3.1.1-windows-x64.zip`，或使用便携版内置更新。
- macOS：根据芯片下载 `ATO-Assistant-Portable-3.1.1-macos-arm64.zip` 或 `ATO-Assistant-Portable-3.1.1-macos-x64.zip`。
- Docker：拉取并重建服务；固定版本用户将 `ATO_VERSION` 改为 `3.1.1`。

手动替换程序时保留原来的 `data/` 与本地素材目录。公开程序包不包含游戏图片、完整故事、音乐、资源包或用户存档。
