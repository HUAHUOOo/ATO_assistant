## 更新

3.5.3 汇总本轮的四组改动：故事页新增「密语记录」工具区（百臂巨人语／巴别语／塞壬语），科技卡分类编辑器改为随包页面并从科技页隐藏入口，资料包分发链路补上密语字形与成品素材，记录表与存档导入器的若干修正。源码与程序包都不含第三方字形与本地素材，需要时随资料包分发。

## 密语记录（故事页）

- 故事页左侧栏新增可折叠的「密语记录」模块，三种密语分页签：**百臂巨人语**、**巴别语**、**塞壬语**。页签切换即时生效，并同步无障碍选中状态。
- 百臂巨人语：16 个符号的键盘用纯 SVG 绘制（不依赖图片资源），可给每个符号记一个 0–9 的数字对应（含「设为未知」），点选输入密文并实时显示译文，未知符号显示 `?`；草稿上限 256 个符号。记录可命名、载入回输入区、删除并撤销删除，保存时把当时的数字读法一起冻结。
- 巴别语／塞壬语：由字形清单驱动（巴别语 58 个字形、塞壬语 26 个），支持字符对应（字母／词语／含义）、字符输入、词组笔记（按连续区间取字形并绑定含义，重复组合只更新含义）、逐字读法与整句读法（未知识别为 `[?]`）。巴别语可按字形分类筛选；塞壬语可切换键盘对照方向辅助辨认（只旋转键盘字形，不推断读序）。
- 「连字成词」区：手工调整空格与标点，或一键生成**离线**分词建议。建议完全在本机计算，不改动原字母与未知标记；词表按需加载（约 1.1 MB），加载失败会明确提示且仍可手工加空格。
- 记录随当前战役保存：输入自动防抖写回战役记录表，只覆盖密语相关字段并用修订号做乐观锁；多标签页冲突时提示并提供「保留本页冲突值／采用存档版本」，读取或保存失败可「重试同步」。改动绑定首次读取时的登录账号，账号被切换后停止保存并提示刷新。密语记录包含在完整状态备份里。
- 字形素材需自备：`story/assets/cryptic/glyphs/*.png` 不进源码与程序包，随 `.atopack` 的 `crypticFiles` 段分发，导入后落回原目录。升级或改名字形时需同步更新目录文件与字形清单。

## 科技与装备

- 科技卡分类编辑器从 `technology/tools/` 迁到随包页面 `technology/card-property-editor.html`，页面内的相对引用（返回科技树、分类脚本、字典、保存接口、卡图路径）同步调整；旧地址保留一个跳转占位页，本机旧书签仍可用。
- 科技页不再显示「编辑分类」入口：入口元素与只服务于它的样式一并移除，条目细分筛选功能不受影响；编辑器页面本身可直接打开。
- 备份自动化补上保护：打包检查会核对编辑器页面及其三个运行依赖确实进包、科技页确实没有暴露入口，并确认旧地址不会进包。

## 资料包与素材

- 新增密语字形分发通道：资源包的 `crypticFiles` 段携带字形 PNG（只认规范命名的 `.png`，单张 ≤128 KB、≤256 张；工程目录没有字形时退回素材库已导入的副本）。便携版／Docker 镜像／APK 都不带这些第三方字形，旧读取方会忽略该段，资料包版本号不变。
- 素材库导出面板新增「包含密语字形」开关（默认勾选）；命令行打包器新增 `--no-cryptic`；构建产物与结果 JSON 记录本次是否带及张数。校验工具会打印字形张数，完整包重建同样带该段。
- 增量打包与校验：字形纳入底包增量索引（未改动的复用旧字节，改动或新增的重新写入），`--verify` 阶段与官方资料、背景音乐、界面图标一并按成员存在性 + SHA-256 复核。
- 导入校验：导入前逐条校验字形路径前缀、单张上限与哈希，导入到素材库并显示张数；路径穿越、伪造哈希、超限文件会被拒绝。安装白名单只放行该字形目录下合规命名的 `.png`，`story/` 树下其它图片仍走原有规则。
- 固定清单新增一类随资料包分发的成品素材条目，并把原先对应的整页扫描条目从清单移除（统一标记「无需拍摄」）。清单总数与图片目标数随之更新，版本标识串追加标记以触发已初始化素材库的增量升级——已拍／已导入的图保留，只补差异。
- 条数变化：条目 2761 → 2841，图片目标 4283 → 4363，其中密语字形 84 条（巴别语 58 + 塞壬语 26）全部「无需拍摄」，文件名清单取自随源码发布的字形清单文件，干净检出也能生成同一份清单。

## Android、Docker 与文档

- Android：APK 侧资料包安装新增字形段解包通道，路径限字形目录下的 `.png`，单文件 128 KB、条目上限 256；不合规条目跳过并计入 skipped，不计入失败。
- Docker：`compose.yaml` 与 `compose.legacy.yaml` 新增字形目录只读挂载（只挂字形子目录，同级清单与词库由镜像提供）；安装脚本会预建该目录，全新部署无需手工建目录；挂载点说明表补充字形目录与故事书图片目录。
- 排除规则：字形 PNG 按后缀拦截且不误伤同目录的程序代码，整目录扫描类素材整目录拦截；误带时打包阶段直接报错，而不是静默发布。
- 文档：README 新增「密语记录」章节（模块位置、三种密语、录入方式、随战役保存与备份范围、字形自备与外部参考说明）；资源包打包文档补充字形段、`--no-cryptic`、旧 APK 兼容性与安装落点。

## 升级说明

- 密语字形需要重新导入资源包才会出现；不导入也可以正常使用，只是字形键盘为空。手动替换程序时保留 `data/` 与本地素材目录。
- Docker 部署需要同步新版 `compose.yaml`（旧版用 `compose.legacy.yaml`）以取得字形目录挂载；单独 `pull` 不会更新宿主机 Compose 文件。
- Android 覆盖安装新 APK 即可；字形随资料包而非 APK 分发。
- 源码部署拉取新代码后刷新页面。故事页脚本查询参数已更新，浏览器会重新拉取数据文件。
