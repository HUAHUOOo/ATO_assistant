## 锚定方法

民间译文与官方译文是同一本原书的两种翻译，用词不同且格式不统一，因此不能照抄官方锚点。逐行重新求锚：

1. **资源图标**：每个图标（`iconId`）在民间正文里有五种写法，全部纳入候选——`词 (English)`、`词((English))`、`（词）`、裸词（如「如果阿尔戈号命运8+」）、遗留符号（`Ψ`=命运、`Λ`=凶险、`Ω`=怒气）。
   - 先按**每个图标的出现次数是否相等**决定顺序配对（顺序在翻译中保持）；
   - 次数不等时，用**译文不变量（数字、页码/编号、拉丁词）做单调对齐**切段，段内次数相等才配对；
   - 候选按质量分层（带英文标签 → 数字相邻的裸词 → 规则动词后的裸词 → 其他），从高到低尝试，避免把散文里的词当成图标；
   - 逐条核对确认属于散文用法的 4 处（如「神明们发出了愤怒的声音」）列入排除表，保持纯文本。
2. **战斗版图**：官方清单项（`16块圆柱`）与民间清单项（`16 x 柱子 (Column)`）按出现顺序配对，**每一项的前导数量必须完全一致**才接受；等级布置图按官方「等级1-3 / 等级4+ / 战前简介」的位置语义，挂到民间的「1-3 级 / 4+ 级 / 3 级+ / 介绍：」对应位置。
3. **叙事雕文图**：官方用一个 `□` 占位（双行四列图）或单个 `□`（单雕文），民间按原书排印保留成 `□□□□`/`□□□□\n\n□□□□`。按条目的占位数量与雕文块顺序配对；只有一个官方占位、民间是多个相邻雕文块时合成一整块替换（如 0354 双行四列位置图）。
4. **两处特殊**：`c2-0-28`/`c2-0-32` 的官方占位是「第一大瀑布水闸」符号，民间写成「第一瀑布水闸符号 (闸门符号)」，按插图插入其后。

剩余 58 处资源图标没有可锚定的民间对应物，原因两类：**民间正文缺该图标**（译文省略或改写成别的说法，例如把官方 `［凶险］` 写成「怒气 (Rage)」，如 `c3-5-50`），或**该条目民间正文为空**。逐条原因见 `tmp/c13-fan/generation-report.json`。
