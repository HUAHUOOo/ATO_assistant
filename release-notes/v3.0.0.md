## 更新

3.0.0 正式版统一了主控制台、阿尔戈号记录表、英雄记录表、故事、地图、AIBP 和科技模块的界面风格：浅色纸面、循环配色、直角控件和细线分隔，减少重复边框与圆角卡片，让记录与操作更紧凑。

**全局主题设置**

- 主控制台的背景音乐下方新增主题设置，支持自动跟随当前循环、固定循环 I–V 配色，以及自定义 RGB。
- 各模块共享主题偏好，已经打开的页面会实时同步颜色；下次打开仍使用已保存的设置。
- 循环 Logo 保留，标题、按钮与搜索 BOSS 等文字随主题配色变化。

**主控制台与记录表**

- 主控制台缩小标题与日期区域，将日期按钮并排排列、日期居中；保存状态移到导航栏，加入地图和故事书入口。
- 减少流程与侧栏之间的空隙，保留必要的面板边界和操作按钮边框；流程完成标记改为循环色方块。
- 战斗科技和结构科技提醒使用更鲜明的颜色；定数框增加底色，内部三部分分别分隔。
- 折叠探索卡库时隐藏已选数量；统一“地图”“科技”等导航用语。
- 阿尔戈号记录表使用相同的循环配色和直角控件，保存状态放在标题下方，返回按钮在右侧使用强调色。
- 统一资源数字框与加减按钮间距，压缩身份数值区以尽量保持单行；抉择矩阵改为铺满宽度的直角网格。

**英雄记录表**

- 每位英雄的身份、技能、回忆、宿命和笔记合为一个连续面板，中间用细线分隔。
- 三曲腿数值在头像右侧区域居中；技能摘要尽量单行显示，展开按钮放在标题行右侧。
- 添加英雄移到顶部工具栏，重置按钮尺寸与其他按钮一致；每位英雄的重置按钮移到标题行。
- 鼠标可从标题行直接拖动排序，触屏可长按标题行拖动；回忆节点排版同步调整。

**故事、地图与战斗界面**

- 故事侧栏根据页面宽度调整宽度，TTS 展开按钮使用强调色；阅读区去掉外层框，故事与灾祸弹窗统一排版。
- 地图界面同步采用循环配色与紧凑控件。
- AIBP 接入循环主题，统一侧栏、战斗区域、按钮及返回入口，界面称呼统一为“始徒”。
- 观星、Trait 和 Token 选择界面改为浅色底与主题控件，调整弹窗滚动与按钮布局。
- 修复卡片放大操作区按钮相互遮挡的问题，移动、翻面等操作分组排列，空间不足时可以滚动。

**科技与装备制造**

- 科技模块新增循环 Logo 标题，接入主控制台的全局主题设置。
- 保存状态、循环标签与工具控件放在同一行，从当前循环选择开始的控件组靠右；标题行缩小高度，窄屏可横向滚动工具栏。
- 隐藏科技树底图时仍保留白底，便于查看节点与条件。
- 已解锁科技、装备制造和详情弹窗统一为直角布局，分组以细线分隔；装备卡片去掉额外白底。

## 下载与升级

本版本为正式版，提供 Android APK、Windows x64、macOS Apple Silicon / Intel 便携版，以及 Docker 镜像 `3.0.0`；正式发布同时更新 Docker 的 `latest` 标签。

- Android：下载 `ATO-Assistant-3.0.0.apk`，覆盖安装。
- Windows：下载 `ATO-Assistant-Portable-3.0.0-windows-x64.zip`，或使用便携版内置更新。
- macOS：根据芯片下载 `ATO-Assistant-Portable-3.0.0-macos-arm64.zip` 或 `ATO-Assistant-Portable-3.0.0-macos-x64.zip`。
- Docker：使用原部署配置执行拉取与重建；固定版本用户将 `ATO_VERSION` 改为 `3.0.0`。

从 2.2.1 正式版升级无需因本次界面更新重新导入资源包。手动替换程序时保留原来的 `data/` 与本地素材目录。公开程序包继续不包含游戏图片、完整故事、音乐、资源包或用户存档。
