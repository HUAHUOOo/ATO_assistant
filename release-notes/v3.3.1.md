## 更新

3.3.1 是 3.3.0 的修复版：修好科技页面打不开的问题，并把循环 I 科技树里「百臂巨人观测」的行位置对齐，让它左侧那条箭头变成直线。程序改动，故事数据与资源包没有变化，不必重新导入。

## 科技页：修复「正在连接...」卡住打不开

- 3.3.0 把科技树的布局元数据搬到 `technology/tech-page-layout.js` 时，页面里又声明了一次同名变量 `PAGE_METADATA`。同一个文档里的两个经典脚本共享全局词法作用域，重复声明会让**整段内联脚本直接以 SyntaxError 结束**——科技页的全部逻辑（读取存档、画科技树、显示状态）都没有执行，页面就停在 HTML 里写死的「正在连接...」上。
- 现在页面不再重复声明，统一从 `window.ATO_TECH_PAGE_LAYOUT` 读取布局；布局文件本身仍保留 `const PAGE_METADATA = [...]` 的声明形式，其它页面（战役简报）和测试照旧。
- `tests/tech-tree.test.cjs` 增加一条守卫：页面内联脚本如果又声明了布局文件已经声明的脚本级名字，测试直接失败（把重复声明加回去验证过，它会报 `PAGE_METADATA`）。
- 如果浏览器还留着 3.3.0 的页面缓存，刷新一次即可；布局脚本的 `?v=` 也换成了新的，科技页与战役简报都会重新拉取。

## 循环 I 科技树：「百臂巨人观测」对齐

- 「百臂巨人观测」(`cycle1_26`) 与它左侧的「强制技力催发」(`cycle1_9`) 行位置差 8.5px，连过去的那条箭头因此会在末端拐一个台阶；现在把该行对齐到 `cycle1_9`，节点整体下移 8.5px，左侧箭头是一条直线。
- 同一份布局被战役简报复用，所以简报里回放科技树时位置一致。
- 科技页与简报页引用布局脚本的版本号都更新了，避免继续使用旧坐标。

## 下载与升级

本版本提供 Android APK、Windows x64、macOS Apple Silicon / Intel 便携版，以及 Docker 镜像 `3.3.1`；Docker 的 `latest` 标签同步更新。

- Android：下载 `ATO-Assistant-3.3.1.apk`，覆盖安装。
- Windows：下载 `ATO-Assistant-Portable-3.3.1-windows-x64.zip`，或使用便携版内置更新。
- macOS：按芯片选择 `ATO-Assistant-Portable-3.3.1-macos-arm64.zip` 或 `ATO-Assistant-Portable-3.3.1-macos-x64.zip`。
- Docker：拉取镜像并重建服务；固定版本用户将 `ATO_VERSION` 改为 `3.3.1`。
- 资源包：沿用 `ATOassets-民间版-3.3.0-q85.atopack`，本次不需要重新打包或导入。

手动替换程序时保留原来的 `data/` 与本地素材目录。公开程序包不包含游戏图片、完整故事、音乐、资源包或用户存档。
