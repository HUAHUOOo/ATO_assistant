## 更新

3.3.0 新增「战役简报」模块：用同一条日期轴回放整场战役的地图翻开与科技树点亮，逐日列出当天发生的事，并能导出 GIF / PDF。安卓版把整个应用（主控台 + 各模块 + 第二屏）开放到局域网；主控台补上 R&R 的第二个追踪框，并把「战役简报」入口放进存档操作区。故事数据修正了 4 段被拇指图标并进上一段的正文，随新版民间版资源包发布。

## 战役简报（新模块）

- 入口在主控台右侧「用户与存档」面板的存档操作里，点开时带着当前循环；页面是独立的 `briefing/`，可以和主控台同时开着。
- 数据只有一个来源：`data/backups/<账号>/daily/` 里的每日存档备份。进入下一天时保留的那份快照当作「那天的结束状态」，相邻两天相减就是当天的新增（翻开的板块、点亮的科技、故事/定数推进、英雄增减、地图流水）。
- 地图回放复用地图模块的板块坐标（`map/nemesis-path.js`），科技树回放复用科技页的布局（见下），所以简报里的图和两个页面长得一样。地图上会画存档里的各类指示物（城市、绿水、侦察船、仇敌、AG、沙尘暴等），带方向的图标画在板块边上。
- 科技树按「首次点亮的日期不晚于当天」点亮，而不是日期字符串相等，于是整棵树会随时间轴逐日长起来，而不是每个节点只在自己那天亮一次。
- 「导出 GIF / PDF」把地图回放与科技树回放各导出一张 GIF，并把逐日记录排成 PDF，打成一个 zip 下载。逐帧渲染与 GIF 编码都在浏览器里做（内置 PHP 没有 GD/Imagick，服务器端画不了图；浏览器也不能自己编码 GIF，用的是随源码发布的 MIT 编码器 `assets/vendor/gifenc.js`），几十天的循环要跑几十秒，进度显示在标题下面。
- 备份里只有状态，所以简报只报**净变化**；装备库存与资源收支保存在浏览器本地，不在存档里，因此简报不包含它们。
- 覆盖哪些天取决于备份还在不在：没有备份的日期显示「无记录」，差分跨过它直接对比前后两份。
- 简报的数据接口是 `briefing/api.php`，只读每日备份；`ATO_DATA_DIR`（见下）可以让它指向一份临时数据目录，回归测试因此不会碰真实存档。

## 安卓：局域网主控台

- 开启第二屏幕后，手机同时是一个局域网服务器：同一网段的设备除了用专用网址看第二屏（`/ss/`），还能打开**主控台地址**（第二屏地址去掉 `/ss/`，也就是根地址）使用主控台与其他模块。
- 局域网里**读和写都开放**：改的是手机上的那份存档，和便携版多设备编辑一样按 section 版本号检测冲突，版本对不上会回 409、页面自己重读重试。
- **登录、注册、退出只能在手机上操作**：这三个请求不在局域网转发，免得别的设备把手机上的登录态换掉或退出。局域网页面用的就是手机上的账号，所以也不需要登录。
- 主控台的第二屏幕卡片新增「局域网主控台网址」和「复制网址」按钮；便携版 / Docker 的局域网入口本来就是完整站点，提示文案会相应写成「登录后使用」（由 `lanSharedAccount` 区分）。
- 局域网地址只在开启第二屏幕期间有效；关掉第二屏幕（或退出登录）会同时关闭这个入口。

## 主控台与科技页面

- R&R 增加「第二个追踪框」：循环 I 的 1 / 2 / 9 号与循环 IV 的 4 号在追踪标上还有一个带 `*` 和段号的框（11 / 22 / 99 / 44）。它只在勾了第一格后出现（避免剧透），勾上会同时标记并前往框内段号；取消第一格时第二格一起清掉。第二格与第一格共用 `surveyConstants.rr` 表、以 `<编号>-goto` 作键，所以「已勾 R&R 数量」和当前 R&R 目标的统计不受影响。
- 「战役简报」是链接，但要和前几个按钮长得完全一样：`dashboard.css` 补齐了链接所需的按钮几何，并把它排进存档操作的按钮行。
- 科技页面的布局数据（各循环图纸尺寸、节点对齐、走线通道）从 `technology/index.html` 抽到 `technology/tech-page-layout.js`，供科技页与战役简报共用一份，节点位置不会两边不一致；页面仍以经典 `<script>` 引入，并保留 `PAGE_METADATA` 这个名字，原有测试不用改。
- 探索卡的规则模块（`assets/exploration-card-rules.js`）此前是 `index.html` 里唯一没有 `?v=` 的脚本资源：便携版用 `php -S`，静态响应没有 `Cache-Control`/`ETag`，一旦某次拿到空响应或半截响应就再也刷不掉，整页渲染会跟着抛错。现在所有 `./assets/*.js` 的 `<script>` 都带 `?v=`，并加了与规则模块行为一致的内联兜底（有回归测试同时锁住这两点）。
- 数据目录可以用 `ATO_DATA_DIR` 指到别处（`api/campaign-state.php`、`briefing/api.php`、`router.php`、`tools/make-briefing-test-save.py` 都认这个变量），跑回归或排查不会动真实存档；`router.php` 会把该目录的顶层名字一并加入私有路径名单，仍然不允许通过 HTTP 访问。

## 下载与升级

本版本提供 Android APK、Windows x64、macOS Apple Silicon / Intel 便携版，以及 Docker 镜像 `3.3.0`；Docker 的 `latest` 标签同步更新。

- Android：下载 `ATO-Assistant-3.3.0.apk`，覆盖安装。
- Windows：下载 `ATO-Assistant-Portable-3.3.0-windows-x64.zip`，或使用便携版内置更新。
- macOS：按芯片选择 `ATO-Assistant-Portable-3.3.0-macos-arm64.zip` 或 `ATO-Assistant-Portable-3.3.0-macos-x64.zip`。
- Docker：拉取镜像并重建服务；固定版本用户将 `ATO_VERSION` 改为 `3.3.0`。用仓库根目录 Apache / NAS 配置的部署请同时更新 compose 配置和站点目录下的 `briefing/`。
- 资源包：`ATOassets-民间版-3.3.0-q85.atopack`（1.40 GiB，4390 个成员 / 4365 张图 / 7 本 4556 段故事 / 19 首背景音乐）。已经装过旧包的可以在素材库里重新导入这一份，或只覆盖 `story/data/storybook-data.js` 拿到故事正文修正。

手动替换程序时保留原来的 `data/` 与本地素材目录。公开程序包不包含游戏图片、完整故事、音乐、资源包或用户存档。
