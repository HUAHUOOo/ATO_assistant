## 更新

**便携版在线更新与回退**

- 支持在本机打开便携版后检查、下载并安装程序更新，更新前备份程序文件，保留存档与本地资源。
- 更新过程校验下载内容，防止多个窗口同时安装；下载失败可重试，安装中断后可恢复。
- 支持回退上一次更新；即使无法连接 GitHub 或当前已是最新版，也能使用已有备份回退。
- 修复 Windows 更新程序自身时的文件占用问题，以及更新响应丢失、备份选择和重复回退等边界情况。

**存档与多设备同步修复**

- 修复旧缓存重新带回已删除记录、首次读取覆盖刚输入内容，以及断线恢复后未同步的问题。
- 战利品重试绑定原账号、存档与周目，避免切换后写错存档；防止响应丢失后重复领取。
- 完整备份导入支持明确清空对应内容，兼容旧版局部备份。
- 科技页保存失败时保留未保存编辑，并阻止直接切换存档造成丢失。
- 英雄同步保留远端排列与独立修改，对不兼容的同时排序提示冲突。

**记录表**

- 补充、修正矩阵摘要与出处说明，统一记录表和矩阵工具的内容，修复没有有效目标的说明链接。

本版本不需要更新资源包。

## 下载与升级

Windows、macOS（Apple 芯片 / Intel）及 Android 请下载对应安装包。由 2.1.9 或更早版本升级时，请先安装本页的 2.2.0 完整包；便携版解压到新目录，并迁移旧目录中的 `data/` 与本地素材目录。在线更新功能用于安装此版本后的后续程序更新。

在线安装与回退适用于已登录、从本机访问的便携版；其他设备可通过安装包升级。资源包仍由原分享渠道获取，不包含在公开安装包中。
