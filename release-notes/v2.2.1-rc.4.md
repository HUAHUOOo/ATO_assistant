## 更新

**AIBP 自定义特性**

- Trait 界面新增“自定义特性”，可填写名称和规则内容，实时预览卡面，并编辑已添加的特性。
- 卡面保留面具、骷髅插画和右上角 X 角标；标题使用隶书，正文使用黑体。文字自动换行、调整字号，内容超出卡面时会提示缩短。
- 自定义特性按使徒分别保存，支持同名特性；清空展示后仍可再次选用。主界面、放大查看与第二屏同步显示修改后的内容。

**AIBP 自定义 Token**

- Token 界面新增自定义文字标记，使用圆形卡底与隶书文字，支持换行、数量调整、拖动定位和放大查看。
- 自定义标记保留文字、数量与位置，第二屏同步显示；同名标记仍可独立操作。
- 更新 Token 可选列表。

**卡图与资源包**

- 哈尔皮“急速适应 / 极速适应”改为竖版特性卡尺寸，民间版与官方版资源包分别使用对应卡面。
- 将自定义特性卡底、自定义 Token 底图加入资产清单，标为无需拍摄。旧素材库会更新清单，新 APK 的导入名单也同步包含这两张图。
- 民间版、官方版 `.atopack` 已按本版清单重新打包，沿用 Q85 图片压缩及大图保留规则。

## 下载与升级

本版本为预发布版，包含此前 2.2.1 预发布版的修正。在本页下载对应平台的 APK 或便携版。

使用新增自定义卡底及修订卡面，需要同时更新程序与资源包。Android 请安装本版 APK 后重新导入新版 `.atopack`；旧 APK 的内置名单无法导入新增卡底。便携版请将新版资源包安装到原项目目录。

自定义特性的名称、内容以及自定义 Token 文字保存在浏览器本地；资源包分发的是卡底和卡图。字体优先使用设备已安装的隶书、黑体，缺少字体时使用替代字体。

公开安装包继续不包含游戏素材、故事书、音乐、资料包或用户存档；两个资源包由原分享渠道提供。
