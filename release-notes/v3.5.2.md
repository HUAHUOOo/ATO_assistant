## 升级说明

- 本次没有新增资源文件，不需要重新下载资源包。源码部署拉取新代码后刷新页面即可；便携版更新程序，Android 覆盖安装新 APK。
- Docker 执行 `docker compose pull && docker compose up -d`。若旧部署的 Compose 尚未包含 `./app/assets/icons:/app/assets/icons:ro`，需先同步新版 `compose.yaml`（旧版使用 `compose.legacy.yaml`），并使用现有资源包中的图标目录；单独拉取镜像不会更新宿主机 Compose 文件。
