## 更新

3.4.0 把主控台界面图标从源码里搬进了资源包：字形不再是写死在页面里的内联 SVG，而是放在 `assets/icons/`、随 `.atopack` 的 `iconFiles` 段分发，页面用 CSS 遮罩取用（颜色仍跟随主题）。记录表把「收割 / 播种」的数字框换成可增删的「记录」下拉，C4 迈达斯之主与半神迪精的 VI 合并成一个共用计数器，并补上旧存档的折算迁移；主控台的 C4 日期轨不再受时间表限制，96 天之后可以一直往下推。战役简报整体改版为与主控台同一套版式。另外故事书数据文件改为每条一行输出（内容不变）。

## 主控台界面图标改走资源包

- 这 30 个字形是从原 App 截图里提取出来的界面素材，属于游戏资源，因此**不再内联进程序源码**：它们现在住 `assets/icons/<名称>.svg`，由资源包的 `iconFiles` 段分发。页面上是 `index.html` 的导航行（6 个）与阿尔戈号知识面板（1 个）、`record/index.html` 的面板标题（10 个）与字段标签（11 个），加上 `record/item-icons.js` 里运行期现搭的 4 个（船体 / 船员 / 难民 / 俘虏）。
- 引用方式换成 CSS 遮罩 + `currentColor`（`--icon-src` 内联变量 + `dashboard.css` / `record/record.css` 的遮罩规则），所以导航图标照旧跟随链接色与悬停色、记录表图标照旧是 `--accent`，尺寸仍按原来的「等包围盒面积」口径。**没有字形时图标位置留白，文字标签不受影响**，不会出现破图或报错。
- **图标现在要靠资源包才有**：全新 clone / 便携版 / Docker / APK 都不含这些字形（导出器与 `api/app-update-policy.php` 同步排除 `assets/icons/`），导入 3.4.0 的民间版或官方版资源包后图标即出现；也可以手动把 SVG 放进 `assets/icons/`。
- 打包链路全线支持 `iconFiles`：民间版 / 官方版打包器、素材库导出与兼容 ZIP、完整包重建，以及安卓 `AtopackStore` 的解包（上限 256 个、单个 1 MB、`image/svg+xml`）。素材库导入后存在 `sources/icons/`，安装时落回 `assets/icons/`。该段与 `bgmFiles` 一样是附加字段，**不改变资料包版本号**。
- **安卓需要 3.4.0 的新 APK** 才会解包这一段；比它旧的 APK 会把它当普通附加字段忽略，图标不会落地（桌面素材库导入不受影响）。
- 三个把字形内联进 HTML 的工具（`tools/embed_dashboard_nav_icons.py`、`tools/embed_record_item_icons.py`、`tools/embed_record_panel_icons.py`）已删除；`tools/build_rare_resource_icon.py` 改为直接读 `assets/icons/glossary.svg`（不再是内嵌副本，重跑输出与旧文件逐像素一致）。
- 提取脚本与说明搬到 **`tools/icon-extract/`**（随源码发布，只有代码与文档，没有游戏素材）；原来那个含截图与中间产物的本地 `icon-extract/` 目录已删除。要重跑整条流水线得先把截图放回去。

## 记录表

- **收割 / 播种记录**：原来「收割计数标记」的数字框 + 备注文本框、「播种计数标记」的数字框 + 备注文本框，合并成两个可增删的「记录」下拉——展开是条目列表（每条右侧「删除」），空的时候显示「还没有记录」，底部「名称或说明」输入框 + 「添加」。内容仍存在原来那两个绑定点上，保存、切换循环、导入导出走的都是页面原有流程；旧存档里的单行文本会自然变成一条记录。
- **C5「补给」字段**移除（不再出现在身份面板）。
- **C4 共用计数器**：迈达斯之主与半神迪精的 VI 原来是两个独立等级格，现在是一个计数器——左键 +1、右键 -1（减到 0 就不再显示数字），计数大于 0 时点亮。前面 I–V 没有全部点亮时不能加数（变暗并带提示），但右键仍可减。
- 旧存档迁移：`state.enemies` 里这两个 VI 的键从 `…:6a` / `…:6b` 变成了 `…:6`。本次补了折算迁移——旧键亮过几格就记几次，折算后删除旧键（对同一份数据重复归一化不会重复累加）；`tests/record-enemy-stage-migration.test.cjs` 锁住这个行为。
- 视觉：模块标题统一黑体与字号、抉择矩阵标题去掉粉底加下边框、外交刻度与抉择矩阵的滚动条改主题细条、命运重掷按钮改白底金框，R&R 与轨道右侧的布局一并理顺。

## 主控台：C4 日期轨不再有上限

- 循环 IV 的日期轨**每天都算战斗日**，不再只在官方时间表列出的日子显示战斗标记；「今日战斗」提醒对任意一天都会出现。
- 「进入下一天」在 Day 96（时间表最后一行）之后继续 97、98、99……不再截断；当前天数超出时间表时，日期轨补出当天那一行（虚线上边线、标题「时间表之外」，可以写备注），顶部 day 输入框也接受任意大的数字。其它循环的行为不变。

## 战役简报改版

- 顶栏改成主控台同一套版式：标题带当前循环图标，右侧新增三个概览数字（已记录 /天、已探索 /格、已点亮 /项科技），「记录范围 D…—D… · 以每日备份为准」作为副标题；「回主控台」变成返回链接。
- 回放区与逐日清单重排：地图 / 科技树面板加编号，地图下方固定图例（当日翻开 / 当前位置），逐日清单改成「日期边栏 + 内容」两栏，活动项加 `aria-current`；宽屏下变成「回放 + 右侧清单」两列。
- 导出更稳：导出中禁用相关按钮并把标签改成「正在导出…」、带旋转指示；失败不再弹 `window.alert`，改成状态行内联提示；加载中重复触发会被挡住。
- 键盘：焦点在输入框 / 下拉框 / 按钮上时不再响应 ←/→ 与空格（此前在输入框里按空格也会触发播放）。
- 主题：简报页面改挂 `assets/theme.css` + `assets/theme.js`，与其它模块共用一套变量；窄屏断点重写，`prefers-reduced-motion` 下关闭导出动画。

## 故事书数据文件格式

- 新增 `format_storybook()`（Python 在 `asset-studio/app/storybook_format.py`，Node 版在 `tools/storybook-format.mjs`）：`books` / `chapters` / `entries` 每个元素各占一行，其余字段保持紧凑。素材库导出、兼容 ZIP、民间版 / 官方版打包器、`build_storybook_placeholder.py`、`import-storybook-pdf.py`、两个 `apply-bgstorybook-*.mjs` 都改用它。
- **故事内容零变化**：条目数、标题、正文、章节结构逐字段一致；只是生成的 `story/data/storybook-data.js` 由一行变成多行（字符数约 +1%，占位文件字节约 +3%）。`story/storybook-placeholder.js` 那 4700 多行的 diff 也纯粹是这次重排。**不需要重新导入资源包**。

## 打包与发布

- 两个 3.4.0 资源包都带上 30 个字形的 `iconFiles` 段，仍按 `--image-quality 85` + `asset-studio/pack-shrink-keep.txt` 豁免名单的同一口径**增量**重建（民间版复用 4383 个成员、官方版复用 6578 个）。
- 修复上一版记录的既有一致性失败：`asset-studio/tests/test_hostile_pack_safety.py` 断言内置清单 2777 条 / 4299 个面，而清单实际是 2761 条 / 4283 个面（三个「退役素材」版本陆续删过条目，断言一直没跟着更新）。现在改为直接与 `fixed_catalog_payload()` 对齐，既能抓到清单被改动，也不会再自己漂移；打包文档里同样过期的数字一并更新。

## 下载与升级

本版本提供 Android APK、Windows x64、macOS Apple Silicon / Intel 便携版，以及 Docker 镜像 `3.4.0`；Docker 的 `latest` 标签同步更新。

- Android：下载 `ATO-Assistant-3.4.0.apk`，覆盖安装。**主控台图标需要这一版 APK**（或桌面端导入资源包）。
- Windows：下载 `ATO-Assistant-Portable-3.4.0-windows-x64.zip`，或使用便携版内置更新。
- macOS：按芯片选择 `ATO-Assistant-Portable-3.4.0-macos-arm64.zip` 或 `ATO-Assistant-Portable-3.4.0-macos-x64.zip`。
- Docker：拉取镜像并重建服务；固定版本用户将 `ATO_VERSION` 改为 `3.4.0`。
- 资源包：`ATOassets-民间版-3.4.0-q85.atopack`（1.40 GiB；4420 个成员 / 4365 张图 / 7 本 4556 段故事 / 19 首背景音乐 / **30 个界面图标**）或 `ATOassets-官方版-3.4.0-q85.atopack`（2.54 GiB；6615 个成员 / 2196 个官方资料含原书扫描图）。**这一版必须导入资源包才会有主控台图标**；已经装过旧包的直接重新导入这一份即可，存档不用动。

手动替换程序时保留原来的 `data/` 与本地素材目录。公开程序包不包含游戏图片、完整故事、音乐、资源包或用户存档。
