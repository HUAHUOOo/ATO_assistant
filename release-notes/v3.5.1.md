## 修复

- 修复 GitHub 分发 APK 导入存档时报 `Unknown section`、整份存档无法写入的问题。Android 本地 API 现支持一次导入全部模块，并在同一把锁内完成账号和版本校验；任一模块冲突时不写入任何模块或备份。完整 ATO 备份和官方 `.jsave` 转换后的部分模块导入均可使用。
- Docker 的 Compose v2 和旧版 v1 配置补上 `assets/icons` 的宿主机挂载，安装脚本与 Docker 打包器同步准备图标目录。新增检查会按资料包清单核对全部资源路径，防止后续素材目录漏挂。

## 更新方式

- Android：安装本 Release 中的 `ATO-Assistant-3.5.1.apk`，然后重新导入原存档；沿用现有签名与应用数据目录。
- Docker：更新安装目录中的 `compose.yaml`（旧版工具更新 `compose.legacy.yaml`），确保有 `./app/assets/icons:/app/assets/icons:ro`，将 SVG 图标放入 `app/assets/icons/`，再拉取镜像并执行 `up -d`。只执行 `pull` 不会更新宿主机上的 Compose 文件。
